# Hardware Design

This directory contains the hardware design files for the **LC Resonant Pulse Generator**.

The system integrates an LC resonant power stage, MOSFET and thyristor switching circuits, isolated gate drivers, and ESP32-based control electronics.

The hardware was designed, assembled, and evaluated in the laboratory.

## Design Files

- [Circuit Schematics](Schematic/) — Electronic circuit design and component connections.
- [PCB Design](PCB/) — PCB layout and related implementation files.

For further technical details, refer to the [Technical Report](../Report/LC_Resonant_Circuit_Technical_Report.pdf).
