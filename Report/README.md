# Technical Report

This directory contains the final technical report for the **ESP32-Controlled LC Resonant Pulse Generator**, developed as a group project for the Industrial Electronics course at the University of Tehran.

## Report Contents

The report covers:

- LC resonant circuit design and component selection
- Capacitor bank and air-core inductor design
- MOSFET and thyristor switching circuits
- TLP250-based isolated gate drivers
- Circuit simulation and current waveform analysis
- ESP32-based switching control
- PCB design, assembly, and laboratory testing
